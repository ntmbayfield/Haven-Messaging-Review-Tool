Haven’s review guidelines

Every review checks the message against this list and scores it. Safeguards are required; essentials and recommended guidelines decide the rest.

How a message is approved

Every safeguard must be met. Then the message is approved if it meets every essential guideline, or if it meets at least 60% of all the guidelines that apply to it.

Anything else is regenerated. Hold is used only when staff need to step in before any version goes out.

How to use the review tool

The tool gives you a second opinion on each of Haven’s drafts. You make the final call in Raiser’s Edge NXT.

Review a draft

  1. In Raiser’s Edge NXT, open Haven’s draft and copy the whole message, from the greeting through the signature. Include the subject line for an email.
  2. Open Review a message and paste the draft into Haven’s message.
  3. Set the context. Choose First message to this donor for an introduction or A later message for anything after it, then pick the purpose and channel. Introduction-only guidelines are skipped for later messages, so this choice changes the result.
  4. If Haven is replying to a donor, open Add context and paste what the donor wrote. This is how the tool spots situations staff need to handle.
  5. Select Review message. A review usually takes under a minute. The first time, Claude asks for permission to run; allow it.

Paste only the draft and, when there is one, the donor’s message. Don’t add giving history, contact details, or other information from the donor’s record.

Read the result

  • Decision, with the reason it was reached. Every safeguard must be met; then a message is approved if it meets every essential guideline or scores at or above the approval bar (60%).
  • Score: the share of guidelines that apply which the message meets, with a count for safeguards, essentials, and recommended guidelines.
  • What needs to change (or What it missed on an approved message) and What the message did right, each tied to a guideline number.
  • Fact check against the knowledgebase: every claim in the message, marked supported, contradicted, sources conflict, or not in the knowledgebase.
  • Also confirm before sending: anything the knowledgebase can’t speak to, such as a donor’s years of support.
  • Apply to future messages and Feedback to give Haven, shown when the decision is Regenerate.

What to do in Raiser’s Edge NXT

Approve

  1. Check everything under Also confirm before sending. Look up anything about the donor in their constituent record.
  2. If every item checks out, choose Send on Haven’s draft.
  3. If an item is wrong or you can’t confirm it, choose Regenerate instead and tell Haven what to change or remove.

An approved message may still miss a few guidelines. If you see the same misses on several approved messages, let the tool’s owner know so the guidelines or Haven’s instructions can be adjusted.

Regenerate

  1. Select Copy feedback in the tool and paste it into Haven’s feedback box. Edit it if you want to add or change anything.
  2. Check the apply to future messages box only if the tool says to. It applies all of your feedback to every message Haven writes, so leave it unchecked when any item is about this donor or one fact.
  3. Choose Regenerate.
  4. When Haven’s new draft is ready, paste the whole thing into the tool and review it again from the start. A new draft can fix one problem and introduce another.

If the fact check shows a claim as sources conflict, the knowledgebase itself needs fixing. Regenerate this draft without that claim, and ask the knowledgebase owner to correct the entry.

Hold

  1. Don’t send or regenerate the draft yet.
  2. Read the reason under the decision. It names what needs a person, such as a complaint, a gift or record question, a request to stop contact, a loss in the donor’s life, or interest in a larger gift.
  3. Pass it to the right staff member. Add an action on the donor’s constituent record assigned to that person, so the follow-up is tracked.
  4. Once staff have responded, come back to the draft. Review it again with the tool, adding a note about what staff did, then send or regenerate.

When you disagree with the tool

You’re the reviewer; the tool is a second opinion. Use your judgment, and choose Send or Regenerate based on what you know about the donor and the message.

  • If the fact check marks something not in the knowledgebase that you know is correct, check the Knowledgebase tab. If it’s missing, ask the knowledgebase owner to add it, both in Raiser’s Edge NXT and on this page.
  • If a guideline seems wrong or too strict, tell the tool’s owner. Guidelines and the approval bar can be changed on the Guidelines tab.
